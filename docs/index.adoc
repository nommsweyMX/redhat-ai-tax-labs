== About this guide

Artificial intelligence is changing how organizations modernize operations,
improve taxpayer services and unlock the value of their data. Adopting it at
scale needs a secure, flexible foundation that connects automation, hybrid
cloud and intelligent workflows.

This guide is the hands-on half of that conversation. It carries six labs that
walk the whole path — standing a model up inside your boundary, teaching it
your agency's vocabulary, serving it through a filing-season peak, grounding
its answers in your published guidance, automating the operational toil around
it, and proving the result to an authorizing official.

Every command in these labs is real and copyable. Every lab runs in two modes:
one that needs nothing but a shell, and one that executes against your own
environment.

== How to run the labs

Every lab is a shell script under `{labs-dir}/`. The scripts run in two modes.

`LAB_MODE=simulate`:: The default. Prints each command followed by the output
you should expect from it. Runs on a laptop with no cluster, no GPU and no
credentials. This is the mode to use during the event.

`LAB_MODE=live`:: Executes each command against your own environment. The
simulated output stays visible on failure, so you can see what should have
happened. Requires the tools named in each lab's prerequisites.

[source,bash]
----
# Walk a lab, one command at a time, pausing for Enter
LAB_PACE=step ./labs/lab01-rhel-ai/run.sh

# Walk every lab end to end without pausing
./bin/run-all-labs.sh

# Run for real against your own cluster
LAB_MODE=live ./labs/lab03-openshift-ai/run.sh
----

.Environment variables
[cols="1,2,1", options="header"]
|===
| Variable | Meaning | Default

| `LAB_MODE`   | `simulate` or `live`                        | `simulate`
| `LAB_PACE`   | `auto` or `step` (wait for Enter)           | `auto`
| `LAB_SPEED`  | Seconds between simulated output lines      | `0.04`
| `NO_COLOR`   | Set to any value to disable ANSI colour     | unset
|===

WARNING: `LAB_MODE=live` runs real commands. Lab 03 includes a load test that
will consume every GPU its namespace can schedule, and Lab 06 reads node
configuration over SSH. Point these at a non-production cluster first.

== A note on the sample content

The notice families, publication references and taxonomy entries in these labs
are illustrative examples written for the exercise. They are shaped like real
agency content so the labs feel real, but they are not authoritative guidance
and no agency has reviewed them. Replace them with your own published material
before generating training data or indexing a corpus.

The numbers in the simulated output — latencies, replica counts, evaluation
scores — are representative figures for a working environment, not measurements
from a specific deployment. Treat them as the shape of a good result, and
measure your own.
